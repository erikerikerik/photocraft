# Local AI showcase screenshots

The three PNGs in this directory were supplied by the fork maintainer for the README on 2026-10-17.
They are unmodified screenshots of PhotoCraft captured on 2026-10-16; no UI or inference output was synthesized.

| File | Capture | What it shows |
|---|---|---|
| `generative-fill-loading.png` | 21:47:50 | CAIM loading LaMa in the Generative Fill progress dialog |
| `fill-menu-selection.png` | 21:49:13 | Lasso selection and the two separate fill menu commands |
| `content-aware-fill-comparison.png` | 21:49:37 | Content-Aware Fill preview; not the AI result |

The supplied captures are contributed for this documentation under the repository's MIT OR Apache-2.0 contribution terms.

The README's before/after images are existing, unmodified PC-06 captures in `agents/receipts/pc-06/`.
They show the same automated run with a rectangular selection, whereas the supplied hands-on captures show a lasso selection.
The AI result and the Content-Aware Fill preview must not be presented as the same operation.
