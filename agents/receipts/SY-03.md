crates/ipp/src/lib.rs` is empty, i.e. both files are byte-identical to the release tag. SPEC's sign-off rule

   intersects `content_end` instead of the runs inside the paragraph being laid out (`prange.end`), so a
   later paragraph at 200 % horizontal scale makes an earlier 100 % paragraph break at half the box width
   and can shift its alignment. Agreed. Routed as **UP-03** (D13: `upfix/text-box-break-scale` from
   `upstream/main`, one upstream PR, then cherry-picked into the fork). Prompt:
   `agents/prompts/local-up-03.md`.

   returns, so a print-server name whose first answer is unreachable reads as `reachable() == false` even
   when a later address serves CUPS. Agreed. Routed as **UP-04**. Prompt: `agents/prompts/local-up-04.md`.
