## Things that went wrong (and what they taught)

1. **Half the dataset pages I went to do not exist any more.** `places2.csail.mit.edu/license.html` is 404
   (three separate attempts, batches 4, 8 and 10), `davischallenge.org/credits.html` 404,
   `commoncanvas.github.io/` 404, `laion.ai/blog/laion-512/` 404, `pathure/GAN_context` (Paris StreetView)
   404, `aimagelab/mimic-dataset` README 404, and `BorealisAI/public-diffusion` is 404 on GitHub with an
   empty Hugging Face search. Lesson: for a licence claim, the HF dataset card and the project README are
   the durable sources; a marketing page is not. It also means the prompt's own example - Public Diffusion -
   no longer has weights to compare, which is a finding, not a miss.
2. **Gated models are a wall, not a slowdown.** `black-forest-labs/FLUX.1-Fill-dev/raw/main/README.md`,
   `open-mmlab/PowerPaint-V1-nosw`, `SmilingWolf/lama-encoder`, `bespin233/MI-GAN`,
   `datasets/stabilityai/PDIP`, `datasets/kakaolaurent/CommonCanvas-2M` all answer **401**. The `api/models`
   metadata (licence tag, safetensors param count) is still readable for FLUX, which was enough to rule it
   out. Lesson: read the API metadata first; only the card needs the gate.
3. **`urllib` refuses an unencoded space.** `rs02f.py` crashed with `InvalidURL: URL can't contain control
   characters` on `?search=public domain images`. Fixed by quoting the query. Cheap lesson, worth knowing
   before writing the next search loop.
4. **A wrong HF path looks like a permission error.** `datasets/kandinsky-community/kandinsky-2-1-inpaint`
   returns 401, not 404, because it is a *model*, not a dataset; retried under `models/` in `rs02k.py`.
5. **Rate limits and bot walls.** `metmuseum.org` answered 429 and `si.edu` 403; `cocodataset.org` and the
   Open Images pages are JavaScript, so a licence sentence cannot be read from the HTML at all. Those rows
   say "could not be read" instead of guessing.
6. **HF search sorted by downloads is not a survey.** The first `?search=inpainting` page is dominated by
   SD/SDXL aesthetic derivatives (one NSFW checkpoint at 12,681 downloads), which is why the small-GAN
   group had to be found with targeted searches (`object removal`, `fill inpainting`, `lama`, `aot`,
   `migan`) rather than by popularity.
