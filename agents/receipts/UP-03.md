## Why the finding does not hold

The claim, from the comment: for a box with more than one paragraph, `break_scale` "keeps every style
run that intersects `content_end` instead of only the runs inside the paragraph being laid out
(`prange.end`)", so a later paragraph at 200 % horizontal scale makes an earlier 100 % paragraph break
at half the available width and can shift its alignment.

`content_end` is not the end of the text. It is the end of *this paragraph's* content:

- `crates/text/src/layout.rs:524` - `for (pi, prange) in split_paragraphs(text).into_iter().enumerate()`,
  one pass per paragraph (`split_paragraphs` at `crates/text/src/layout.rs:1134`).
- `crates/text/src/layout.rs:529` - `let content_end = strip_break(text, &prange);`, and `strip_break`
  (`crates/text/src/layout.rs:1159`) trims the paragraph terminator, so `content_end <= prange.end`.
- `crates/text/src/layout.rs:660` - the filter is
  `ri == si0 || (rs.max(prange.start) < end.min(content_end))`.

A run that starts after the paragraph has `rs >= prange.end >= content_end`, so
`rs.max(prange.start) = rs` is not `< end.min(content_end)` and the run is dropped. `content_end` is
the **tighter** bound of the two: switching the comparison to `prange.end`, which the finding asks
for, would let in a run that only touches the paragraph's own line break. There is also no index
drift between the three arrays the filter indexes: `out.styles.push(s)` runs once per run
(`crates/text/src/layout.rs:483`), and `run_starts` is scanned from the same `runs`
(`crates/text/src/layout.rs:485-492`), so `out.styles.len() == runs.len() == run_starts.len()`.

## The test the prompt asks for

Two paragraphs in one box; the second at `horizontal_scale: 2.0`; the first paragraph's line ranges
and `x0`/`x1` must be the same as when the first paragraph is alone, for Left, Right and Center.
Name: `a_later_paragraphs_larger_scale_leaves_the_earlier_paragraphs_breaks`, placed after
`horizontal_scale_breaks_paragraph_lines_at_the_scaled_width` in `crates/text/src/tests.rs`.

```rust
#[test]
fn a_later_paragraphs_larger_scale_leaves_the_earlier_paragraphs_breaks() {
    let mut e = TextEngine::new();
    let p1 = "The quick brown fox jumps over the lazy dog again and again until the paragraph wraps";
    let p2 = "The second paragraph is set at twice the horizontal scale of the first paragraph";
    let plain = CharStyle { font_family: "Inter".into(), size_pt: 12.0, ..Default::default() };
    let wide = CharStyle { font_family: "Inter".into(), size_pt: 12.0, horizontal_scale: 2.0, ..Default::default() };
    for align in [TextAlign::Left, TextAlign::Right, TextAlign::Center] {
        let para = ParagraphStyle { align, ..Default::default() };
        let alone = with_para(TextLayer { text: p1.into(), runs: vec![TextRun { len: p1.len(), style: plain.clone() }], shape: TextShape::Box { x: 10.0, y: 0.0, width: 120.0, height: 1000.0 }, ..Default::default() }, para.clone());
        let both = with_para(TextLayer { text: format!("{p1}\n{p2}"), runs: vec![TextRun { len: p1.len() + 1, style: plain.clone() }, TextRun { len: p2.len(), style: wide.clone() }], shape: TextShape::Box { x: 10.0, y: 0.0, width: 120.0, height: 1000.0 }, ..Default::default() }, para);
        let l1 = e.layout(&alone, 72.0);
        let l2 = e.layout(&both, 72.0);
        let first = |l: &crate::TextLayout| l.lines.iter().filter(|ln| ln.range.end <= p1.len()).map(|ln| (ln.range.clone(), ln.x0, ln.x1)).collect::<Vec<_>>();
        let (one, two) = (first(&l1), first(&l2));
        assert!(one.len() > 2, "{align:?}: the first paragraph wraps on its own: {}", one.len());
        assert_eq!(two.iter().map(|t| t.0.clone()).collect::<Vec<_>>(), one.iter().map(|t| t.0.clone()).collect::<Vec<_>>(), "{align:?}: the second paragraph's scale must not break the first one differently");
        for (a, b) in two.iter().zip(&one) {
            assert!((a.1 - b.1).abs() < 0.01 && (a.2 - b.2).abs() < 0.01, "{align:?}: same placement: {a:?} vs {b:?}");
        }
    }
}
```
